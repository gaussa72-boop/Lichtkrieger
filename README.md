# LICHTKRIEGER — Dark Mirror Realms

A playable browser-game prototype for the LICHTKRIEGER universe.

## Play
Open `index.html` locally or serve the repository root as a static website.

## Current playable vertical slice
- Four realms: Ashen Kingdom, Elysium/Paradise, Infernum/Hell, and the Mirror Void.
- Three playable archetypes: Wanderer, Shadow Warden, Quantum Runner.
- Keyboard movement (WASD/arrows), melee attack (Space), interact (E), realm shift (Q), chronicle map (M).
- Procedurally placed environment silhouettes, hostile shades, a guardian encounter, portal, health and quantum energy.
- Display quality profiles: Pixel, HD, 4K and 8K labels. Actual render scale is clamped to device capabilities.

## Vision / production roadmap
This prototype is the first playable foundation, not a finished AAA-scale open-world game. The full target is an original action-RPG with:
- Seamless regions, vertical traversal, settlements, dungeons, sanctuaries, infernal zones and mirror dimensions.
- Original characters, factions, companion arcs, bosses, wildlife, merchants and quest chains.
- Combat systems, animation, weapons, armor, skill trees, crafting and progression.
- Futuristic technology concepts as fictional in-world systems: quantum gates, neural interfaces, nanoforges, orbital habitats, plasma relics, synthetic ecosystems and autonomous guardians.
- Save profiles, cloud persistence, accessibility, controller support and optional multiplayer.
- Real 3D rendering and GPU streaming as separate production stages. Resolution selection alone does not create native 4K/8K assets or GPU streaming.

## Controls
- Move: WASD / arrow keys
- Attack: Space
- Interact: E
- Change dimension: Q
- Chronicle map: M

No external runtime or third-party script is required for the current prototype.
